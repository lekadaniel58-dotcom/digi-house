# Fonti catalogo Pennellificio Duemila

Le immagini e i collegamenti tecnici del reparto `pennelli-accessori.html` provengono dal catalogo ufficiale:

- Sito e pagine prodotto: <https://www.pennellificio2000.com/>
- Catalogo tecnico PDF: <https://www.pennellificio2000.com/wp-content/uploads/2021/08/pennellificio2000-2018-pennelli.pdf>

Le fotografie sono state scaricate localmente dalla directory ufficiale `wp-content/uploads/products_img/` per garantire il caricamento stabile su GitHub Pages. Le schede riportano varianti e misure indicate nella richiesta e collegano ogni famiglia alla relativa pagina prodotto ufficiale.

Le schede, il layout e i colori della pagina sono DIGI HOUSE; non viene riprodotto il branding grafico del produttore.
